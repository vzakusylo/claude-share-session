Your conversations are already on disk for every account. Only the sidebar and the scheduled-task list are per account. claude-share-session mirrors them — so account B continues exactly where account A stopped.

What you get

🔁Shared sidebar

Every account sees every session. Newest copy wins, nothing is deleted silently, backups before each write.

⏰Shared scheduled tasks

A task fires in whichever account is open. The latest "last run" wins — no repeated runs after switching.

🧭Briefing at session start

Who worked here, when, on which branch, how the last turn ended, and the resume command.

🛡️Safe by design

Each account writes only its own files. Notes from other sessions are data, never instructions. Hooks fail open.
